Responsive Dropdown

  • Shows the file count at a glance
  • Works for one file or twenty
  • Reuses an existing component, so it’s quick to build
  • Files stay hidden until the menu is opened

Side Drawer

  • Clean when closed
  • Covers the document when open
  • Takes an extra tap to switch files

Browser-like Tabs

  • Familiar from web browsers
  • Gets crowded after three or four files
  • Costly to build and maintain
